# Source register template

This file describes the sources for a specific run. No run-specific source
manifest or data is included in this structural release. Replace this template
for an authorized run; record only information appropriate for the intended
audience and protect confidential or personal data.

## Field and period mappings

For each source, document mappings to the standard concepts used in the run,
including observation period, exposure, number of claims, policy or claim
keys, and any optional fields. Record units and any ambiguity for actuary
review.

## Provenance and restrictions

Record citations, licenses, permissions, retention requirements, and
redistribution restrictions for each source. Do not include credentials,
unnecessary personal information, or data that the intended audience is not
authorized to receive.
