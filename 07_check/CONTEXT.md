## Job
Four-eye check — independently review the drafted report and model against
`checklist.md` before the work is approved for its intended use.

## Steps
Run `checklist.md` against the current report and underlying inputs, period
alignment, model, assumptions, and outputs. Apply conditional checks only when
the corresponding data or model component is used. Record findings alongside
the draft, never as a bare "passed" stamp.

## Four-eye mechanism
The reviewer must be independent of the report drafter. For a demonstration, a
fresh agent with no drafting context may perform the pass, with the actuary
reviewing and signing off; for an engagement, follow the applicable independent
review and approval requirements.

## ⏸ Human-in-the-loop gate
This is a real pause point, not a formality: **The accountable actuary reviews
the findings and explicitly signs off before `08_client_review/`.** The
reviewer's independence and approval process must suit the engagement.

## Done when
Findings are logged and shown to the actuary before `08_client_review/` — this stage never silently clears a draft.
